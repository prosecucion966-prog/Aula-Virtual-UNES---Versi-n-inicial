# 🎓 Aula Virtual - Diplomado en Docencia Universitaria (UNES)

Sistema de aula virtual con base de datos en Supabase para el Diplomado en Docencia Universitaria de la Universidad Nacional Experimental de la Seguridad (UNES).

## Características

- 📚 9 unidades curriculares completas con guías de estudio
- 📝 18 evaluaciones (2 por unidad): Test de opción múltiple + Completar palabras
- 🔄 2 intentos por evaluación con calificación automática
- 💾 Base de datos en Supabase (matrícula, progreso, certificados)
- 🎓 Certificado de aprobación al completar las 9 unidades
- 📊 Panel de progreso en tiempo real
- 📱 Diseño responsive

## Acuerdo

Basado en el Acuerdo N° 0000737 - Consejo Universitario UNES
Caracas, 22 de Mayo de 2026 · Vigencia 2026

## Tecnologías

- HTML5, CSS3, JavaScript (Vanilla)
- Supabase (PostgreSQL + REST API)
- Vercel (Hosting)
